A one-page newspaper front page for Monday 23 November 2026: 40 verified
world-news stories across 7 regions, headlined by the collapse of COP31 in
Antalya, with a world map of the main news locations, a UTC timeline of the
day, a by-the-numbers strip and a markets box. Every headline, number and
name was checked against reporting dated 23 November 2026 (Reuters, BBC,
UN News, CNN, Bloomberg, The Hindu, Le Monde, Al Jazeera, Daily Mirror,
LiveScore, TSN, Gulf News).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This copies `entry.png` (1024×1024) to `$MAKEFUN_OUTPUT_DIR/entry.png`
(default `/output`) and verifies the copy byte-for-byte. Python 3.13,
standard library only, no network.
